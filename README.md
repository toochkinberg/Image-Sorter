# Возможности

- **Просмотр всех изображений**: Отображение всех изображений из исходной и управляемых директорий с пагинацией.
- **Просмотр по папкам**: Просмотр изображений в конкретной папке (Исходная, Детали, Повреждения, Корзина, Чёто не то).
- **Режим сортировки**: Сортировка изображений из исходной директории по категориям с помощью горячих клавиш или кнопок.
- **Режим удаления из Корзины**: Перемещение изображений из папки Корзина в другие папки или их окончательное удаление.
- **Режим удаления из Чёто не то**: Перемещение изображений из папки Чёто не то обратно в исходную директорию или их окончательное удаление.
- **Статистика папок**: Отображение количества изображений и их общего размера (в ГБ) для каждой папки.
- **Круговая диаграмма**: Визуализация распределения изображений по папкам.
- **Сохранение состояния**: Сохранение прогресса сортировки в JSON-файл для продолжения работы позже.

## Требования

- Python 3.7+
- Необходимые библиотеки Python:
  - `streamlit`
  - `streamlit-hotkeys`
  - `pandas`
  - `matplotlib`

Установите зависимости с помощью:

```bash
pip install -r requirements.txt
```

## Структура директорий

Приложение ожидает исходную директорию с изображениями и создаёт следующие управляемые папки:

- **Детали**: Для изображений деталей автомобиля.
- **Повреждения**: Для изображений с повреждениями.
- **Корзина**: Для изображений, которые нужно пересмотреть или удалить.
- **Чёто не то**: Для изображений, которые не удалось загрузить или которые некорректны.

Исходная директория указана в переменной `SOURCE_DIR` в скрипте. По умолчанию:

```python
SOURCE_DIR = r"ПУТЬ_ДО_СЫРОЙ_ПАПКИ"
```

Обновите этот путь, чтобы он указывал на вашу директорию с изображениями.

## Использование

1. **Установка исходной директории**:
   - Измените переменную `SOURCE_DIR` в скрипте, чтобы указать путь к папке с изображениями.

2. **Запуск приложения**:
   - Запустите приложение с помощью Streamlit:
     ```bash
     streamlit run image_sorter.py
     ```

3. **Режимы работы**:
   - **Просмотр всех изображений**: Просмотр всех изображений из всех директорий с опциями пагинации (50, 100, 200, Пользовательское количество или Все изображения на странице).
   - **Просмотр по папкам**: Просмотр изображений в выбранной папке.
   - **Режим сортировки**:
     - Просмотр одного изображения за раз из исходной директории.
     - Используйте горячие клавиши или кнопки для перемещения изображений:
       - **Q**: Переместить в "Детали"
       - **W**: Переместить в "Повреждения"
       - **E**: Переместить в "Чёто не то"
       - **Delete**: Переместить в "Корзина"
     - Изображения, которые не удалось загрузить, автоматически перемещаются в папку "Чёто не то".
   - **Режим удаления (из Корзины)**:
     - Просмотр изображений в папке Корзина.
     - Перемещение в "Детали" или "Повреждения" либо окончательное удаление.
   - **Режим удаления (из Чёто не то)**:
     - Просмотр изображений в папке Чёто не то.
     - Перемещение обратно в исходную директорию или окончательное удаление.

4. **Статистика папок**:
   - На главной странице отображается таблица с количеством изображений и их общим размером (в ГБ) для каждой папки.
   - Круговая диаграмма показывает распределение изображений по папкам.

5. **Сохранение состояния**:
   - Приложение сохраняет прогресс в файл `sorting_state.json`, отслеживая обработанные изображения и текущие индексы для режимов сортировки и удаления.
   - Прогресс сохраняется между сеансами.

## Горячие клавиши

- **Q**: Переместить в "Детали" (в режиме сортировки).
- **W**: Переместить в "Повреждения" (в режиме сортировки).
- **E**: Переместить в "Чёто не то" (в режиме сортировки).
- **Delete**: Переместить в "Корзина" (в режиме сортировки).

## Примечания

- Приложение работает с изображениями распространённых форматов (`.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`).
- Изображения, которые не удалось загрузить в режиме сортировки, автоматически перемещаются в папку "Чёто не то".
- Круговая диаграмма и статистика папок обновляются динамически на основе текущего состояния директорий.
