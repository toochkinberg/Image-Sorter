# Image Sorter - README

## Техническая информация

### 🚀 Быстрый старт
1. **Клонируйте репозиторий**:
   ```bash
   git clone <repo>
```

2. **Установите зависимости** из requirements.txt:
 ```bash
 pip install -r requirements.txt
 ```

3. **Настройте файл .env** (см. Настройка .env).
4. **Запустите приложение**:
```bash
streamlit run image_sorter.py
```

3. **Откройте в браузере**: http://localhost:8501

### 📁 Структура проекта

```
📁 project/
├── image_sorter.py          # 🎯 Основной скрипт
├── .env                     # ⚙️ Настройки
├── requirements.txt         # 📦 Зависимости
├── action_history.log       # 📝 История действий (лежит в облаке)
└── stats_cache.json         # 📊 Кеш статистики (лежит в облаке)
└── 📁 Ваши папки (в облаке, кроме TEMP):
	├── src                  # Исходники (SOURCE_DIR)
    ├── BATCH1_LEV/          # 🅱️ Батч Лев
    ├── BATCH2_DAN/          # 🅱️ Батч Ден
    ├── BATCH3_YURA/         # 🅱️ Батч Юра
    ├── Детали/              # ✅ Детали
    ├── Повреждения/         # ⚠️ Повреждения
    ├── Корзина/             # 🗑️ Корзина
    ├── Чёто не то/          # ❓ Необработанное
    └── TEMP/
        ├── prev/            # 👁️ Предпросмотр
        └── buff/            # ⚡ Буферы сортировки
```

### 🔧 Настройка .env

Создайте файл .env в корне проекта и заполните его следующим образом:

```env
############ ПУТИ К ПАПКАМ (ОБЯЗАТЕЛЬНО ИЗМЕНИТЕ) ############
SOURCE_DIR='ПУТЬ_К_СЫРЫМ_ДАННЫМ'

DETAILS_DIR='Детали'
DAMAGES_DIR='Повреждения'
TRASH_DIR='Корзина'
BROKEN_DIR='Чёто не то'

BATCH1_DIR='BATCH1_LEV'
BATCH2_DIR='BATCH2_DAN'
BATCH3_DIR='BATCH3_YURA'

TEMP_PREVIEW_DIR='TEMP/prev'
TEMP_BUFFER_DIR='TEMP/buff'

############ НЕ ИЗМЕНЯТЬ ############ 
USER_IDS=admin,lev,dan,yura

STATS_CACHE_FILE=stats_cache.json

ACTION_HISTORY_FILE=action_history.log
```

- **SOURCE_DIR**: Папка с исходными изображениями.
- **BATCH*\_DIR**: Папки для батчей пользователей (lev, dan, yura).
- **DETAILS_DIR, DAMAGES_DIR, TRASH_DIR, BROKEN_DIR**: Категории для сортировки.
- **TEMP_PREVIEW_DIR, TEMP_BUFFER_DIR**: Временные папки для предпросмотра и буферизации.
- **ACTION_HISTORY_FILE**: Файл лога действий.
- **USER_IDS**: Список ID пользователей (не изменять).
- **STATS_CACHE_FILE**: Файл для кеширования статистики.

## Функциональные особенности

### 👥 Пользователи и батчи

Приложение поддерживает **многопользовательскую работу** с четырьмя пользователями:

|**ID**|**Роль**|**Батч**|**Доступ**|
|---|---|---|---|
|admin|Админ|Все папки|Полный: просмотр, сортировка, статистика, распределение|
|lev|Пользователь|BATCH1_LEV|Сортировка своего батча + общие категории|
|dan|Пользователь|BATCH2_DAN|Сортировка своего батча + общие категории|
|yura|Пользователь|BATCH3_YURA|Сортировка своего батча + общие категории|

**Особенности для админа**:

- Распределение изображений из SOURCE_DIR по батчам (равномерно или в конкретный батч).
- Доступ к просмотру всех папок.
- Расчет и обновление статистики.

### ⚡ Хоткеи

Для ускорения сортировки используются **горячие клавиши**:

| **Русская раскладка** | **Английская раскладка** | **Действие**                                             |
| --------------------- | ------------------------ | -------------------------------------------------------- |
| **Й**                 | **Q**                    | Переместить в **Детали**                                 |
| **Ц**                 | **W**                    | Переместить в **Повреждения**                            |
| **У**                 | **E**                    | Переместить в **Чёто не то** (только в общей сортировке) |
| **Delete**            | **Delete**               | Переместить в **Корзину** / Удалить                      |

**Примечание**: Хоткеи работают в любом языке ввода (русский/английский).

### 📊 Статистика

- **Доступна всем пользователям**, но **обновляется только админом**.
- **Кешируется** в stats_cache.json для быстрого отображения.
- **Содержит**:
    - **Таблицы**: Количество и размер (в ГБ) для исходных папок, батчей и категорий.
    - **Графики**: Два круговых графика (распределение по исходникам/батчам и по категориям).
- **Обновление**: Админ нажимает кнопку "Рассчитать статистику" на вкладке "Стата".

### 🗂️ Буферизация

Каждый режим сортировки использует **буфер** для ускорения работы и минимизации доступа к диску:

- **Размер буфера**: 50 изображений (максимум).
- **Хранение**: Временные копии файлов в TEMP_BUFFER_DIR.
- **Автозаполнение**: Буфер пополняется автоматически при опустошении.
- **Очистка**: При смене пользователя или режима сортировки (TEMP_BUFFER_DIR и буферы сбрасываются).

|**Режим**|**Источник**|**Буфер**|**Действия**|
|---|---|---|---|
|Общая сортировка|Батч пользователя|image_buffer|Q (Детали), W (Повреждения), E (Чёто не то), DEL (Корзина)|
|Корзина|Корзина/|trash_buffer|Q (Детали), W (Повреждения), DEL (Удалить)|
|Необработанное|Чёто не то/|broken_buffer|Q (Вернуть в Source), DEL (Удалить)|

**Особенности**:

- Изображения копируются в TEMP_BUFFER_DIR и проверяются на валидность.
- Рандомный выбор файлов для равномерной обработки.

### 📝 История действий

- **Хранится** в action_history.log.
- **Формат записи**: Время | Пользователь | Файл | Действие.
- **Отображение**: Пагинация по 50 записей на вкладке "Журнал".
- **Пример**:
```text
2025-10-27 20:55:45 | lev | img_001.jpg | Перемещено в Детали
2025-10-27 20:55:46 | dan | img_002.jpg | Удалено
```

### 🎮 Основной функционал

#### **Вкладка 1: Стата**

- **Таблицы и графики**: Распределение по исходникам, батчам и категориям.
- **Кнопка "Рассчитать"**: Только для админа, обновляет stats_cache.json.

#### **Вкладка 2: Предпросмотр**

- **Пагинация**: 50/100/200/все изображения на странице.
- **Сетка**: 5 столбцов для отображения.
- **Временные копии**: Файлы копируются в TEMP_PREVIEW_DIR.
- **Доступ**: Админ видит все папки, пользователи — свой батч и категории.

#### **Вкладка 3: Сортировка**

- **3 режима**: Общая сортировка, Корзина, Необработанное.
- **Хоткеи и кнопки**: Для быстрого перемещения/удаления.
- **Буферизация**: Каждый режим использует свой буфер (50 изображений).
- **Очистка**: Автоматическая при смене режима/пользователя.

#### **Вкладка 4: Журнал**

- **Полная история**: Все действия пользователей.
- **Пагинация**: 50 записей на страницу.
